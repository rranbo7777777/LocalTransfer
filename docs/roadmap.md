# 实施路线

## 已完成：阶段 1，协议与 Windows/Android 纵向闭环

- 共享协议、状态机、分块计划、票据与命名策略。
- Windows WPF、HTTPS 协调端、可信设备、二维码配对和托盘。
- 手机上传、电脑下载队列、断点文件接收与幂等完成确认。
- MAUI Android UI、安全存储、扫码、文件选择和系统分享入口。
- 核心、协议和 HTTPS 双向集成测试；Android Debug APK 构建。

## 下一阶段：真机联调与可靠性验收

1. 在专用 Wi-Fi、电脑热点、手机热点三种拓扑中联调 Windows 与 Android。
2. 验证 Windows 防火墙提示、睡眠唤醒、Wi-Fi 切换、应用前后台切换。
3. 验证微信和 QQ 的单文件、多文件、图片、视频、文档分享入口。
4. 增加 Windows 发送队列持久化和任务历史数据库。
5. 执行断网、重复请求、源文件变化、磁盘不足、哈希错误和应用崩溃恢复测试。
6. 完成 10 GB 单文件、100 文件批量、重名和零字节文件验收。

## iOS 阶段

1. 在具备 .NET 8 iOS workload 的环境恢复 `net8.0-ios` 构建。
2. 配对 Mac，完成模拟器和真机构建、Keychain、证书固定和本地网络权限验证。
3. 建立 App Group。
4. 用原生 Swift 创建 Share Extension，将微信/QQ 分享内容复制到 App Group 暂存区。
5. 主 MAUI 应用读取暂存清单并进入相同上传协议；扩展本身不执行长时间网络传输。
6. 完成签名、Provisioning Profile、后台/前台切换和系统分享回归测试。

## 发布准备

- Windows 安装器、首次启动专用网络说明和卸载清理策略。
- Android 签名密钥、Release AAB、备份策略和隐私声明。
- 设备移除、证书轮换、可信设备自动接受开关与操作日志。
- 依赖升级与漏洞扫描；评估从 MAUI 8 升级到受支持版本。
