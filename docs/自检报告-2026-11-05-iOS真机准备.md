## 真机验收清单（装机后按序执行）

1. **装机**：Actions 跑「iOS打包」→ 下载 `LocalTransfer-ios-unsigned` → Sideloadly/AltStore 签名安装 → 设置 → 通用 → VPN与设备管理 信任开发者证书。
2. **首启**：允许「本地网络」权限；不授权则一切连接必失败（属预期行为）。
3. **配对**：电脑端「创建配对信息」→ 扫码 → 电脑批准 → 手机显示「已连接」。
4. **发送**：选 1 个小文件发送 → 电脑确认 → 电脑提示保存成功。
5. **接收**：电脑端发文件给手机 → 弹窗接收 → 「文件」App → 局域传输 → Received 能看到文件。
6. **大文件**：10 GB 单文件，全程保持亮屏（应用自动维持），观察进度与续传。
7. **断网恢复**：传输中关 Wi-Fi 数秒再恢复，确认续传闭环生效。
8. **换网络（预期行为）**：电脑换 IP/换热点后，iOS 不会自动发现，重新扫码配对即可——平台限制，不算缺陷。
9. **失败路径**：电脑端拒绝/超时，手机提示文案应包含重新扫码指引。

## 已知限制（平台固有，非缺陷）

- 组播自动发现需要 Apple 特批 entitlement，免费签名不可得；已改为明确跳过并文档化。
- 免费 Apple ID 签名 **7 天过期**，过期后重新签名安装，数据不丢。
- Share Extension 未实现：分享入口只能用应用内文件选择器。
- 电脑端侧载识别 iPhone 需装 Apple 官网版 iTunes + iCloud（非微软商店版）。
